Python mein Conditionals ka matlab hota hai kisi condition (shart) ko check karna aur uske mutabiq code execute karna.

1. if statement
if ka use tab hota hai jab hum kisi condition ko check karna chahte hain.

2. else statement
else tab execute hota hai jab if ki condition False ho.

3. elif statement
elif ka matlab hai Else If.

Jab humein multiple conditions check karni hon to elif use karte hain.
